# Private execution artifacts

Generated task selections, source prompts, answer keys, model exchanges,
per-task outcomes, tuning notes and score tables belong under `private/`,
`runs/`, `evidence/` or the external benchmark volume, never tracked source.
These paths are ignored. Do not force-add them or embed their contents into
tracked specifications, release notes or source files.

Generic execution tools and product changes may be versioned. Release claims
must remain accurate; private development records are not a public submission.
Existing historical publications are not altered by this storage rule.
