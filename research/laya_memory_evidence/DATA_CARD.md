# Public Hugging Face dataset card contract

The public dataset repository is generated by `export_public_dataset.py` and
must remain compatible with the Hugging Face Dataset Viewer.

The first visible section is a real-row preview with these columns:

| ID | Expected | Category | Observation | Why |
| --- | --- | --- | --- | --- |
| stable row ID | memory decision | memory class | original-language user turn | short evidence explanation |

The downloadable Parquet files additionally expose normalized memory, exact
structured meaning (subject, predicate/intent, value, scope, time, durability
and prior-state relation), evidence, supersession and duplicate target IDs,
bounded conversation context, language,
source, confidence, agreement, split, input digest and rubric version.

Publication gates:

1. The repository visibility is public.
2. `README.md` renders without placeholder examples.
3. Every preview row exists byte-for-byte in a published Parquet split.
4. The Dataset Viewer loads train, validation and calibration.
5. The visible allocation matches the manifest, targets 100,000 accepted rows,
   never falls below 20,000 and discloses any early-stop reason.
6. Raw teacher responses, provider response IDs and private country metadata
   are not included in the public view.
7. Source licenses and pinned revisions ship beside the data.
8. The final manifest proves zero generated, translated, synthetic or
   hand-authored conversation rows.
9. Every accepted row has complete Codex first-pass and self-review history;
   Claude coverage and any credit-exhaustion fallback are shown exactly.

The guarded publisher targets
`atmem/atmem-laya-memory-decisions-v1`, verifies the exact accepted-row count,
checks the preview table, and explicitly sets the Hugging Face repository to
public visibility.
