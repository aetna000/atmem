## Reproduction

Use private temporary directories and installed test credentials only. Build the
bridge first with `npm run build --prefix integrations/openclaw`. The repository
`.venv/bin/atmem` must contain the tested wheel. Install mem0ai==2.0.20 and
ollama==0.6.2 in a separate probe venv; start local Ollama with nomic-embed-text
and qwen3:1.7b available. Install isolated OpenClaw 2026.9.2/2026.9.3 binaries and
use an authenticated Claude CLI. Each invocation needs a fresh nonexistent root:

```sh
PROBE_PYTHON tools/run_mem0_openclaw_live.py --root PRIVATE_NEW_ROOT \
  --openclaw EXACT_OPENCLAW_BINARY --scenario inject
```

Repeat for default, withhold, tools, tool-error and tools-missing on both binary
versions. The script records commands/configuration, real hook/event observations,
strict assertions, flight reports and summaries. It never enables shared-channel
delivery. For the separately labelled role-play journey:

```sh
ATMEM_TEST_PYTHON=PROBE_PYTHON ATMEM_TEST_COMMAND=INSTALLED_ATMEM \
ATMEM_PROVIDER_FIXTURE=ABSOLUTE_REPO/tools/smoke_mem0_roleplay.py \
PYTHONPATH=ABSOLUTE_REPO node integrations/openclaw/test/delegated-journey.mjs
```
