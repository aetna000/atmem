Agent frameworks

Native adapters for your framework

OpenClaw

Fully managed: bridge, hooks, native-memory copy, freeze and restore

atmem openclaw install
atmem control verify
# already on AtMem 2.1?
atmem openclaw upgrade
atmem control verify

Pydantic AI

A native capability; pass atmem_task_id in run dependencies

cap = PydanticAIAtMemAdapter(
  manager, identity
).capability()
agent = Agent(model,
  capabilities=[cap])

LangChain / LangGraph

Native middleware; task id through configurable

mw = create_langgraph_middleware(
  manager, identity)
agent = create_agent(
  model=model,
  middleware=[mw])

Adapters automate capture, governed retrieval, injection, exposure proof and turn and tool evidence, without replacing your model, tools, conversation history or LangGraph checkpoints.

Let’s talk about the agent frameworks. AtMem isn’t a framework, it governs the one you already use. For OpenClaw the integration is fully managed. “atmem openclaw install” installs the matching npm bridge, discovers agents and workspaces, installs the hooks, starts in shadow mode, restarts the gateway and verifies the connection. If you were already on AtMem 2.1, “atmem openclaw upgrade” is idempotent and upgrades in place. For Pydantic AI there’s a native capability. You build an identity with agent, workspace and subject IDs from the control plane’s agent topology, wrap it in the AtMem adapter, and pass the capability to your Agent. A task ID can come through run dependencies. For LangChain and LangGraph there’s native middleware. Same identity, and you pass the middleware into create_agent. The task ID comes through configurable, and there’s guidance for async, multi-agent and low-level StateGraph integrations. In every case the hooks automate authenticated capture, governed retrieval, context injection, exposure proof and turn and tool evidence. They don’t replace your model, your tools, your conversation history or your LangGraph checkpoints. Anything else, a custom agent or a SaaS worker, uses the generic control MCP contract we saw earlier.
