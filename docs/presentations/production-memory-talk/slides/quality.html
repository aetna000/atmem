Now evaluation. Earlier I said “it seems to remember” is not a release gate. So what is? First, an offline release gate. “atmem benchmark run” executes twenty-four isolated cases covering extraction, contradiction, recall, withholding, prompt injection, privacy, memory poisoning and fallback behaviour. The rule is strict: safety has to be perfect, and every other quality metric must stay at or above its checked-in baseline. If a change makes memory more helpful but less safe, the gate fails. Second, external comparison, done carefully. These benchmarks test whether an agent can use remembered experience to answer a question or complete a task, not just whether search results look relevant. On a 23-question sample of LongMemEval-V2, AtMem answered 5, Mem0 OSS 1 and AgentRunbook-R 4. On a 30-task sample of DolphinBench, where a task passes only when every required check passes, AtMem passed 9 and Mem0 7. On DolphinBench’s individual checks it was 32 of 97 against 27 of 97. I want to be honest about what these numbers are. They’re frozen, roughly five percent development samples, not full official or leaderboard scores. The arms used matched tasks and the same reader and judge routes, and every attempted case, including system failures, stayed in the denominator. The Mem0 Dolphin environment lacked two optional extras. And absolute accuracy is still low for everyone. The point isn’t a victory lap; it’s that we measure, publish the protocol, and keep the caveats attached.
