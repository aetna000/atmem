Now the tracking side. The Agent Black Box answers one narrow operational question: what did the host observe the agent and its tools doing during this run? The table shows the flight events a runtime can emit. turn.input when a turn starts. model.input with prompt, system and history digests plus provider and model. context.disposition, which is the one I care about most: was memory injected, empty, withheld or failed, with the exact placement envelope digest and the candidate IDs that were considered. Then tool.requested and tool.completed for every tool call, model.output with token usage, and turn.ended with success or cancel and a reason. This table is the content-minimising projection: digests, counts and names. When full-fidelity capture is configured, the exact prompts, context, model exchanges, tool arguments and results, and supported multimodal originals are kept separately in an encrypted evidence vault. On the right: the timeline is appended to the control evidence store and protected by a hash chain scoped by migration and kind, so you can’t quietly delete or reorder an event. One honest caveat: digests are fingerprints, not encryption or anonymisation. A low-entropy value can be guessed and compared, so treat the evidence database and exports as sensitive records.
