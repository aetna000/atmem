If you remember one sentence from this talk, make it this one: AtBot proposes, AtMem decides. AtBot is AtMem’s private intelligence companion. It’s installed automatically and pinned to the exact AtMem version. It can use a local Ollama model, a local OpenAI-compatible server, a hosted provider, or a deterministic fallback with no model at all. AtBot’s job is to propose: extract a memory candidate, rank what might be relevant, or suggest a change to a task. But a proposal is just a proposal. AtMem revalidates every one of them against scope, policy and provenance, then either commits it with a receipt or withholds it. That separation matters for two reasons. First, security. A prompt injection that fools the model still can’t write memory or widen scope, because the model never holds that authority. Second, availability. If AtBot or its model is down, AtMem keeps going with safe local capture and hybrid ranking. Memory authority and agent operation never depend on a hosted model. AtBot isn’t an independent agent and it isn’t a second memory authority. It’s a headless component managed by AtMem.
