# Guided onboarding

Discovery is read-only. The shared state contract turns failed checks into an
explicit plan; mutating actions require consent. Each successful action is
checkpointed, so rerunning resumes instead of duplicating it. Activation is
blocked until synthetic capture, paraphrase, context, evidence, and restore
readiness are all proven. Rollback applies compensators in reverse receipt
order and disables activation.

The CLI and dashboard should render this same JSON contract. Health details and
memory explanations are evidence-based and redact prompts, memory text, keys,
and connection strings. Existing beta users can discover and plan without
changing their setup, then explicitly apply or roll back.
