# AtMem 2.2.4 — clean upgrades and OpenClaw 2.0

AtMem 2.2.4 makes upgrades replace stale background runtimes, adds tested
OpenClaw 2.0 installation behavior, and moves the bundled AtBot companion to
the current Pydantic AI generation.

## Fixed

- `atmem openclaw upgrade` is idempotent when the matching bridge is already
  installed.
- A running dashboard is restarted with the upgraded Python executable before
  bridge verification, preventing an old process from continuing to display an
  old AtMem version.
- Dashboard daemon status identifies a version or Python-environment mismatch
  and tells the operator to restart it.
- OpenClaw 2026.8.1 plugin installation supplies the new explicit capability
  consent and trusted-source confirmation required by that host release.
- The OpenClaw manifest declares startup and hook/tool capability activation and
  an explicit plugin API compatibility floor.

## Framework compatibility

- AtBot `0.1.0a3` uses Pydantic AI 2.x without unnecessary direct OpenAI or
  Jiter pins.
- AtMem's native Pydantic AI capability is tested with Pydantic AI 2.36.0.
- The native LangChain/LangGraph middleware is tested with LangChain 1.3.18 and
  LangGraph 1.2.11.
- The three current framework releases resolve and pass together in one clean
  Python environment.

## Upgrade

```bash
python -m pip install --upgrade atmem==2.2.4
atmem openclaw upgrade
atmem control verify
```

For a non-OpenClaw integration with a running dashboard:

```bash
atmem dashboard daemon restart
```

Existing 2.1.x and 2.2.x databases, record IDs, audit chains, memory mode,
OpenClaw restore data, and AtBot provider settings are retained.

## Verification

The release gate covers Python 3.10 through 3.13, installed AtBot and AtMem
wheels, authentic public-2.1.0 and public-2.2.3 in-place database upgrades, current Pydantic AI
and LangChain/LangGraph adapters, and the OpenClaw 2026.8.1 bridge typecheck,
build, test, and smoke suites.
