# AtMem 2.3.8b3 — Hermes preview and corrected bridge metadata

AtMem 2.3.8b3 is the corrected prerelease for the Hermes adapter, paired with
the already published AtFlows 0.1.4b2 observer. It includes the same fail-closed
Hermes payload and status tooling as 2.3.8b2, plus aligned OpenClaw README and
bridge metadata so the packaged plugin passes its release checks.

## Install or upgrade

```bash
python -m pip install --pre --upgrade "atmem==2.3.8b3"
atmem init
atmem status
atmem hermes install
atmem hermes status --json
```

AtMem pins `atflows==0.1.4b2`. Install the companion independently with
`python -m pip install --pre --upgrade "atflows==0.1.4b2"` when needed.

## Compatibility and limits

The matching bridge is `openclaw-memory-atmem@2.3.8-beta.3`. Hermes activation
still requires a reviewed scoped connection in the Hermes runtime; installing
the payload alone does not select a provider or create credentials. The Hermes
observer and AtFlows receiver are loopback/local by default and intentionally
exclude prompts, tool arguments, responses, authorization headers, and keys.

This is a prerelease. Existing AtMem databases need no migration.
