# AtMem 2.2.6 beta 2

AtMem 2.2.6b2 makes the delegated context-provider feature fully
provider-neutral while preserving the native AtMem default and the beta 1 wire
contract.

## What changed

- Removed provider-specific names, presets, defaults, examples, fixtures, and
  documentation from current repository and package content.
- Require operators to supply an explicit provider ID in the CLI, dashboard,
  and control API.
- Regenerated the signed conformance fixtures with a neutral test identity and
  deterministic fixture-only Ed25519 key.
- Renamed Spec 003 to `003-delegated-context-provider`.
- Reject delegated responses immediately when their declared content length
  exceeds policy.

The wire contract ID remains `atmem.delegated-context-provider.v1`; compatible
providers do not need a product-specific AtMem integration.

## Install or upgrade

```bash
python -m pip install --pre --upgrade atmem==2.2.6b2
atmem openclaw upgrade
atmem delegated status
atmem control verify
```

Existing installations remain in native AtMem authority mode unless an
operator explicitly registers and enables a delegated provider for exact user,
agent, and workspace scopes.
