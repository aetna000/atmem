# AtMem 2.2.5 — SDK-neutral default install

AtMem 2.2.5 supersedes 2.2.4 after final public-install verification found that
AtBot's default Pydantic AI extra could upgrade OpenAI and Jiter across a shared
agent environment. The default install is now SDK-neutral.

## Fixed

- AtBot `0.1.0a4` uses its built-in standard-library OpenAI-compatible client
  for local Ollama and compatible hosted endpoints.
- Installing or upgrading base AtMem no longer installs or upgrades Pydantic
  AI, OpenAI, or Jiter.
- Pydantic AI support remains available explicitly through
  `atmem[pydantic-ai]`; LangChain/LangGraph support remains available through
  `atmem[langgraph]` or `atmem[frameworks]`.
- OpenClaw 2026.8.1 support, stale-dashboard replacement, idempotent bridge
  upgrades, and the 2.1.0/2.2.3 persisted-state upgrade gates from 2.2.4 remain
  intact.

## Upgrade

```bash
python -m pip install --upgrade atmem==2.2.5
atmem openclaw upgrade
atmem control verify
```

Existing memory, evidence, configuration, restore state, and provider settings
are retained.

If 2.2.4 was installed into a shared environment before this superseding patch,
run `python -m pip check`. Pydantic AI/OpenAI packages left behind by pip are no
longer AtMem requirements and may be reconciled according to the other agent
packages in that environment.
