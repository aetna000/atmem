# AtMem 1.0.0 — stable product rename and OpenClaw memory control plane

AtMem 1.0.0 is the first stable release under the AtMem name.

## Public names

- Install the Python engine with `pip install atmem`.
- Run the CLI with `atmem`.
- Import the Python API from `atmem`.
- The managed OpenClaw bridge is `openclaw-memory-atmem@1.0.0`.
- The OpenClaw plugin and explicit tools use the `atmem` namespace.
- New local state is stored beneath `~/.atmem`.

The previous prerelease product name and prerelease package identities are not
part of the AtMem 1.0 public API.

## Included product

- model-agnostic SQLite memory engine and MCP server;
- provenance, lifecycle governance and hash-chained audit evidence;
- lexical, graph and optional semantic investigation search;
- OpenClaw native-memory copy and continuous shadowing;
- verified activation and reversible restoration;
- loopback dashboard for memory, review, audit and flight investigation;
- content-minimizing Agent Black Box timelines for OpenClaw runs.

## Install

```bash
python -m pip install atmem==1.0.0
atmem --version
atmem openclaw install
```

Do not install the npm bridge separately. The AtMem installer selects the
matching bridge, binds the exact Python executable, copies existing OpenClaw
memory, restarts the gateway and verifies the loaded integration.

## Claim boundary

A valid Agent Black Box flight proves retained timeline integrity and observed
hook closure. It does not semantically validate an answer or prove an external
real-world outcome without an independent system-of-record verifier.
