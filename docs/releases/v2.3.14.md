# AtMem 2.3.14

Agent Memory now shares AtMem.ai’s pink branding: the original logo with a #F3A2B4 dot in light and dark modes, pink buttons and hover surfaces, and darker rose text for contrast. Semantic success, warning and error colours retain their meanings. AtFlows 0.1.7 brings the matching dashboard theme.

## Install or upgrade

Python 3.10–3.13:

```sh
python -m pip install --upgrade atmem==2.3.14
atmem --version
atmem status
```

Optional coding memory: `python -m pip install --upgrade 'atmem[code]==2.3.14'`. Back up the AtMem home, database, encryption keys and evidence. Let active work finish, stop services you own, upgrade, then restart clients and dashboards. No schema migration or new opt-in is required. Existing settings and data remain compatible.

Exact compatibility: atmem==2.3.14, atflows==0.1.7, atmem-atbot==0.1.1 (unchanged) and openclaw-memory-atmem@2.3.14. Upgrade the bridge with `atmem openclaw upgrade`, then check `atmem openclaw status`. Standalone AtBots and AtSys remain separate products.

This appearance release changes neither memory authority nor retrieval, authentication or provider behavior. No new model evaluation or benchmark result is claimed. Existing platform support and limitations remain as documented in 2.3.13. Website publication is a separate owner-reviewed step.
