# AtMem 2.2.3 — dependency-safe upgrades

AtMem 2.2.3 keeps automatic AtBot installation compatible with shared Python
agent environments and supports both Pydantic AI 1.x and 2.x request contexts.

## Fixed

- AtMem installs the published `atmem-atbot==0.1.0a2` companion.
- AtBot stays on Pydantic AI 1.x, OpenAI SDK 2.x, and Jiter below 0.14 instead
  of upgrading a shared environment across incompatible major versions.
- The native Pydantic AI adapter reads model identity safely across both the
  1.x and 2.x `ModelRequestContext` shapes.
- The documented `atmem openclaw upgrade` command remains available and the
  matched OpenClaw bridge version is 2.2.3.

## Upgrade

```bash
python -m pip install --upgrade atmem==2.2.3
atmem openclaw upgrade
atmem control verify
```

Existing 2.1.x and 2.2.x databases, record IDs, audit chains, memory mode,
OpenClaw configuration, and AtBot provider settings are retained.

## Verification

The release gate covers Python 3.10 through 3.13, Pydantic AI 1.x and 2.x
adapter behavior, clean-wheel dependency consistency, the 2.1.0 in-place
upgrade drill, AtBot packaging, and the OpenClaw typecheck, build, test, and
smoke suites.
