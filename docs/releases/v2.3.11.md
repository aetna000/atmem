# AtMem 2.3.11

Stable release of the 2.3.11b1 package line, coordinated with AtFlows 0.1.5.
Ordinary governed memory creation, scoped retrieval, context provision and
encrypted evidence retain their existing defaults. AtFlows now ships its
Windows private-state protections as stable. This promotion changes release
metadata, compatibility pins and current documentation; action-routing and
standing-fact research remain explicit opt-ins.

## Install or upgrade

Python 3.10–3.13:

```sh
python -m pip install --upgrade atmem==2.3.11
atmem --version
atmem status
```

Optional coding memory:

```sh
python -m pip install --upgrade 'atmem[code]==2.3.11'
atmem code --help
```

Back up the AtMem home, database, encryption keys and evidence before upgrading.
Let active tasks finish, stop services you own, upgrade, then restart connected
clients and dashboards. Existing data is retained; the 2.3.10 migration guidance
still applies. Installing does not call a model, activate a new provider or
enable research routing. Never remove keys needed to decrypt existing evidence.

## Exact compatibility

- `atmem==2.3.11`
- `atmem-atbot==0.1.1` (separate legacy memory-proposal companion)
- `atflows==0.1.5` (stable Windows ACL/private-state promotion)
- `openclaw-memory-atmem@2.3.11` (matching npm bridge)

Upgrade the OpenClaw integration through the Python-owned installer:

```sh
atmem openclaw upgrade
atmem openclaw status
```

The standalone `atbots` agent platform is a different distribution, not a
replacement for `atmem-atbot`. AtSys is separately installed; native workspace
supervision supports macOS/Linux. AtMem and AtFlows retain their supported
Windows/Linux/macOS paths; native Hermes integration is unavailable on Windows.
AtMem Code requires explicit project/host enablement. Prior Copilot qualification
is limited to the documented CLI versions, not every future host release.

## Research opt-ins and measured results

The action planner, governed writer experiment and source-linked standing facts
remain optional research APIs. Normal `Memory.remember`/`recall` and default
context behavior do not enable them. A matching quote is occurrence evidence,
not semantic entailment. The derived research store is not a canonical memory
authorization boundary. Provider-dependent experiments may make paid calls.
Stable packaging does not upgrade those experiments into general guarantees.

The [final self-tested DolphinBench run](https://huggingface.co/datasets/atmem/dolphinbench-routed-v4-20261101)
passed 479/600 tasks (79.83%). Its frozen i3/routed-v4 source and installed
2.3.10b1 base are recorded in the dataset. That is the historical benchmark
artifact, not a fresh benchmark of the 2.3.11 wheel. No new scored run is part
of this promotion. Per-action data, failed checks and write-failure classes
remain available without combining successful reads with failed writes.

## Boundaries

Evidence discovery remains source-backed, bounded, read-only and explicitly
registered. Retrieval is not proof an agent used a fact or learned. Model
availability, provider quotas and end-to-end task success are not guaranteed.
AtFlows observes traces and reported prices; it cannot grant memory authority.
Website source review, owner merge and production deployment are separate
publication states. Historical beta releases remain available for reproducibility;
2.3.11 is the current stable installation target.
