# AtMem 2.3.10 stable promotion qualification

This promotion starts from public main `30d9677`, containing the released
2.3.10b1 product. The published beta wheel has SHA-256
`d5d3a23e3005392f8291f8c1201b3226752420f5841128e9eb40346d7f2d3c2b`.
The exact stable release commit and rebuilt artifacts are recorded by the
GitHub publication workflow; this document does not predeclare a passing run.

## Promotion boundary

- AtMem: `2.3.10b1` → `2.3.10`.
- OpenClaw bridge: `2.3.10-beta.1` → `2.3.10`.
- AtBot: stable `0.1.1`, unchanged source and exact dependency pin.
- AtFlows: stable `0.1.4`, unchanged exact dependency pin.
- Product changes are restricted to reported version/bridge-install constants.
  No retrieval, authorization, storage, prompts, thresholds, model configuration,
  dependency or default changes are part of this promotion.
- Tests, metadata, current install instructions, release documentation and website
  source manifest are refreshed; historical beta/benchmark evidence is retained.

`tools/check_stable_promotion.py` compares all shipped AtMem product files
against the published beta wheel and refuses any difference other than the two
explicit version constants. It additionally checks unchanged companion and
bridge implementation source against the published beta tag.

The local comparison passed: **370 shipped product files** checked; only
`atmem/openclaw_install.py` and `atmem/mcp/server.py` differ, each solely by its
explicit version constant. Companion/bridge implementation source and dependency
and Python-version contracts are unchanged. Stable product payload digest:
`aaa2147a89256cf8a59aac01e1603c81a75208e21a135adb40fdc20ae4ea50b1`.

## Applicable release gates

Run Python and companion regression suites, bridge typecheck/build/test/smoke,
stable release metadata validation, website documentation checks, wheel/sdist
build and Twine checks, installed-artifact smoke and persisted upgrade checks.
Hosted CI qualifies the Python/Linux matrix, native Windows and macOS paths.
Do not tag on a failing/dirty commit or replace unavailable gates with claims
about the earlier beta's tests. Final registry and package checks happen after
publication, not merely after a source push.

The beta's [historical platform qualification](v2.3.10b1-qualification.md) remains
identified as beta preparation and is not silently rewritten as stable evidence.
The completed benchmark dataset remains pinned to the tested beta artifact.

## Coverage and compatibility

Ordinary memory and governance, Code structure/experience, AtFlows handoff,
AtBot and OpenClaw retain their existing contracts. Discovery is scoped,
read-only and explicitly enabled by an authorized host. Optional semantic
retrieval still requires a configured embedding backend and native SQLite
capabilities; the base package does not install Torch or download a model.

Not every supported agent CLI supplies the same hooks. POSIX-only host exceptions
are not claimed on Windows. Website owner review/merge and deployment remain
separate from PyPI/npm/GitHub publication.
