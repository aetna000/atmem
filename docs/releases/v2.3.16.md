# AtMem 2.3.16 — Portable agent handoffs

OpenClaw can offer source-linked evidence to Hermes. The recipient checks its own workspace grant and re-reads the source revision before receiving or returning a quote. A correction or expiry can withhold the handoff. The encrypted run survives a broker restart.

Open **Sessions → Agent handoffs → Recorded examples** for the measured example. The original answer AX-100 failed a pytest assertion. After a memory correction, AX-745 passed the same assertion. Project runs connect a test, ticket, incident or pull request to the source span used by a particular agent. JUnit results come from the imported report. Other engineering references carry operator-reported status.

## Install or upgrade

Back up your existing AtMem home using your normal backup procedure. Use the Python environment that owns your existing installation.

```sh
python -m pip install --upgrade 'atmem[encrypted,team-mcp]==2.3.16'
python -m pip check
atmem --version
atmem dashboard
```

Base installations can use `atmem==2.3.16`. Existing OpenClaw installations can run `atmem openclaw upgrade` followed by `atmem openclaw status` to verify bridge 2.3.16. The release pins AtBot 0.1.1 and AtFlows 0.1.8. Existing memory needs no manual migration. Cross-host execution requires explicit host grants and full encrypted evidence capture. The default local team uses a single reader. Adaptive and mandatory review are opt-in.

## Measured behavior

On ten frozen synthetic tasks, the single reader scored 10/10 using 1,357 total model tokens, adaptive review scored 10/10 using 1,547, and mandatory review scored 9/10 using 1,955. All three abstained correctly four times. ChatGPT coverage exercised the OAuth plugin transport with Firebase emulators. The framework checks used deterministic tool selection. Local Ollama supplied no dollar charge.
