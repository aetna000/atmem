# AtMem 2.2.2 — dependency-safe upgrades

AtMem 2.2.2 is a packaging compatibility patch. It keeps the automatic AtBot
installation from upgrading shared OpenAI SDK installations across a major
version boundary.

## Fixed

- AtBot is updated to `atmem-atbot==0.1.0a2`.
- The companion now stays on Pydantic AI 1.x, OpenAI SDK 2.x, and the compatible
  Jiter range used by the supported LangChain, OpenAI Agents SDK, LiteLLM,
  LlamaIndex, and Instructor installations.
- Installing or upgrading AtMem no longer selects OpenAI SDK 3.x merely because
  it is the newest release on PyPI.
- The documented `atmem openclaw upgrade` command remains available and the
  matched OpenClaw bridge version is 2.2.2.

## Upgrade

```bash
python -m pip install --upgrade atmem==2.2.2
atmem openclaw upgrade
atmem control verify
```

Existing 2.1.x and 2.2.x databases, record IDs, audit chains, memory mode,
OpenClaw configuration, and AtBot provider settings are retained.

## Verification

The release gate covers Python 3.10 through 3.13, dependency consistency in an
installed wheel, the 2.1.0 in-place upgrade drill, AtBot packaging, and the
OpenClaw typecheck, build, test, and smoke suites.
