# AtMem 2.2.6 beta 3

AtMem 2.2.6b3 adds supported provider-side adapters for deployments where
Mem0, LangGraph, or Pydantic AI remains the context-decision authority and
AtMem independently verifies, delivers, and records the result.

## What changed

- Added independent `atmem[mem0]`, `atmem[langgraph-provider]`, and
  `atmem[pydantic-provider]` optional extras.
- Added one shared bounded loopback runtime, closed proposal model,
  deterministic context builder, receipt generator, and Ed25519 signer.
- Added `atmem provider init|serve|start|stop|status|doctor|remove`.
- Enforced Mem0 user, agent, and workspace filters on every search.
- Added synchronous and asynchronous LangGraph invocation with strict final
  decisions and interrupt rejection.
- Added Pydantic AI structured-output handling with explicit local or hosted
  egress attribution.
- Added redacted health, decision, latency, dependency diagnosis, safe
  lifecycle management, and 25-request concurrency coverage.
- Added clean-base and independent-extra release gates.

Native AtMem context authority remains the default. Installing, initializing,
or starting a provider does not register or enable delegated authority.

## Install or upgrade

```bash
python -m pip install --pre --upgrade atmem==2.2.6b3
atmem openclaw upgrade
atmem control verify
```

Install only the context provider you need:

```bash
python -m pip install --pre 'atmem[mem0]==2.2.6b3'
python -m pip install --pre 'atmem[langgraph-provider]==2.2.6b3'
python -m pip install --pre 'atmem[pydantic-provider]==2.2.6b3'
atmem provider --help
```

The existing `openclaw-memory-atmem@2.2.6-beta.2` bridge remains compatible;
this release does not change its npm contract.
