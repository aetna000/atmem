## Preparation versus publication

### Coverage boundaries

Platform totals are not interchangeable coverage. Native Windows skips
POSIX-only benchmark/controller fixtures, the POSIX Hermes native installer and
macOS-private controller paths. Native Windows product storage, discovery,
managed providers, security, bridge and installed-package paths are tested.
Optional upstream checkouts, external SDKs and paid/live-provider tests are
skipped when unavailable. macOS optional-framework tests separately pass
22 checks; SDKs absent from the Windows full-run environment are not claimed as
tested. The macOS expected failure is the existing Muse installed prompt-hook
canary, not a newly passing integration.

Windows owner-only ACL checks reject broad grants, reparse/special paths and
unverifiable permissions. SYSTEM and local Administrators remain trusted OS
authorities. The origin-metadata-absent isolated-CLI exception remains POSIX-only;
normal authenticated-owner integration is retained on Windows.

Production npm dependency audit reports zero vulnerabilities. The pinned
development OpenClaw toolchain reports eight upstream findings (two moderate,
five high, one critical); this is not a clean development-toolchain audit.
Upstream compatibility/security review remains required before changing that pin.
