# AtMem 2.3.8b4 — Hermes preview

AtMem 2.3.8b4 is the corrected beta release for the Hermes adapter. It pairs
with the published AtFlows 0.1.4b2 observer and includes aligned package,
OpenClaw bridge, README, and website-documentation metadata.

## Install or upgrade

```bash
python -m pip install --pre --upgrade "atmem==2.3.8b4"
atmem init
atmem status
atmem hermes install
atmem hermes status --json
```

AtMem pins `atflows==0.1.4b2`; install it directly when needed:

```bash
python -m pip install --pre --upgrade "atflows==0.1.4b2"
```

The matching OpenClaw bridge is `openclaw-memory-atmem@2.3.8-beta.4`.

## Compatibility and limits

This beta is opt-in and does not require a database migration. Hermes still
needs a reviewed, scoped runtime connection before it can become the active
memory provider; installing the adapter does not create credentials or change
provider selection. The local observer and AtFlows receiver remain loopback
by default and omit prompts, tool arguments, responses, authorization headers,
and keys from telemetry.
