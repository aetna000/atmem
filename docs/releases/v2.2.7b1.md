# AtMem 2.2.7b1 — clearer evidence and selective memory

This is the first **beta of AtMem 2.2.7**, paired with OpenClaw bridge
`2.2.7-beta.1` on npm's `beta` channel. AtBot independently becomes stable
`0.1.0`. Publication is complete only after the release workflows succeed and
GitHub, PyPI and npm artifacts are verified.

## What changed since 2.2.6

- A calmer dashboard with compact status, a colour legend, background reviews
  separated from foreground runs, collapsed technical detail and automatic
  evidence updates. Completed runs distinguish individual failed tool calls;
  event links identify the affected step and recorded time.
- Local timestamps include seconds, milliseconds and timezone. Stored evidence
  remains ISO 8601 UTC with full microsecond precision, including exact seconds.
- Automatic OpenClaw recall requires direct original-query support by default.
  Always-on persona becomes opt-in; enabled persona records are excluded from
  recall to avoid duplication. Explicit memory search remains available.
- Tool errors retain bounded, best-effort-redacted diagnostics and independent
  error digests. Known wrapped web-fetch errors expose their HTTP status rather
  than the security notice. Missing historical reasons remain explicit.
- Two strictly validated progress-card result formats can represent one logical
  call without false conflict alarms. Both raw hashes are preserved; changed
  results, unknown formats and contradictory outcomes remain visible.
- Delegated local CLI identity can use explicit isolated-operator mapping;
  scoped terminal tool observations improve supported CLI lifecycle evidence.
  Missing owner identity still fails closed outside that explicit scope.
- AtBot 0.1.0 stabilizes the existing headless companion interface. It proposes
  and ranks; AtMem remains the authorization and canonical storage authority.

## Install or upgrade

```bash
python -m pip install --upgrade 'atmem==2.2.7b1'
atmem openclaw upgrade
atmem control verify
atmem dashboard daemon restart
```

The exact beta pin selects the prerelease without requiring a global `--pre`
policy. AtMem installs `atmem-atbot==0.1.0`; its managed OpenClaw installer pins
`openclaw-memory-atmem@2.2.7-beta.1`. For AtBot alone:

```bash
python -m pip install --upgrade 'atmem-atbot==0.1.0'
atbot --version
```

For a new OpenClaw integration, run `atmem openclaw install` after the Python
installation. Optional extras retain the exact beta version, for example
`python -m pip install --upgrade 'atmem[mem0]==2.2.7b1'`.

## Configuration and migration

No new database migration or rewrite of historical evidence is required.
Existing explicit persona opt-in is respected. To apply selective context to
an existing OpenClaw setup:

```bash
openclaw config set plugins.entries.memory-atmem.config.persona.enabled false
openclaw config set plugins.entries.memory-atmem.config.recall.requireDirectSupport true
openclaw gateway restart
```

This changes selection, not stored memory. To intentionally restore always-on
persona, set `persona.enabled` to `true`; `recall.requireDirectSupport=false`
restores the older rank-only selection behavior. Weak matches can reappear in
that mode. Existing authenticated delegation, approvals and authority scopes
remain in force. Earlier semantic-epoch and authenticated-delegation migration
requirements still apply; see [2.2.6b11](v2.2.6b11.md#migration-and-opt-in-behavior).

Reload the dashboard once after upgrade to load its new JavaScript. Subsequent
run updates happen automatically while the page is visible.

## Compatibility and honest limits

Python release gates cover 3.10–3.13. Host inspection included OpenClaw 2026.9.1;
recorded delegated fixtures include other exact versions described in
[implementation evidence](../implementation-evidence/003/). These checks do not
establish universal host, shared-channel identity or tool lifecycle coverage.

A green completed run means the host reported completion, not that every tool
succeeded or that its answer is correct. Red tool errors remain visible inside
completed runs; amber notes identify uncertain evidence or review needs.
Historical hash-only conflicts and missing diagnostics are not retroactively
repaired. Live polling is a view of recorded evidence, not an independent agent
heartbeat. Redaction is bounded and best-effort, not a universal secret detector.

The stricter automatic context gate may withhold useful background context;
explicit recall is available when more context is needed. AtBot's stable version
does not certify every optional model/provider or the future enterprise roadmap.

## Release validation

Local Python 3.12: 1,455 tests passed; 13 optional-dependency tests skipped in
that minimal environment. AtBot: 17 passed. OpenClaw prepack (build, typecheck,
tests and smoke journeys), distribution metadata checks, source-distribution
rebuilds and fresh installed-wheel checks passed. An isolated upgrade from
published 2.2.6 preserves record identity, recall and audit/control state.
The GitHub workflows enforce the Python matrix, real provider-extra SDK checks,
framework checks and installed artifacts before publication.
