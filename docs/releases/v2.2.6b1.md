# AtMem 2.2.6 beta 1

AtMem 2.2.6b1 adds optional delegated context authority without changing the
native AtMem default.

## What is new

- Provider-neutral signed context-result verification with Storizon as the
  first intended provider.
- Explicit registration and activation bound to user, agent, and workspace.
- Exact one-segment OpenClaw delivery with provider authorization and host
  delivery recorded separately.
- Atomic replay, idempotency, late-result, and conflicting-turn protection.
- Fail-closed provider errors; native fallback only by a second explicit policy.
- CLI and collapsed dashboard status/actions with no private key or context
  content stored in control evidence.

## Install the beta

```bash
python -m pip install --pre --upgrade atmem==2.2.6b1
atmem openclaw upgrade
atmem delegated status
atmem control verify
```

Existing installations remain in their current native shadow/active mode until
an operator registers and enables a delegated provider. Schema migration is
additive and preserves existing memory, candidate, restore, and flight data.
