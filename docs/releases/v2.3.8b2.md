# AtMem 2.3.8b2 — Hermes preview and safer companion wiring

AtMem 2.3.8b2 is a prerelease for testing the Hermes adapter and the paired
AtFlows 0.1.4b2 observer. It keeps the existing encrypted memory and control
plane contracts while adding a packaged, integrity-checked Hermes plugin
payload and status inspection.

## Install or upgrade

Use the prerelease channel explicitly:

```bash
python -m pip install --pre --upgrade "atmem==2.3.8b2"
atmem init
atmem status
```

AtMem pins `atflows==0.1.4b2` for the coordinated beta. If AtFlows is used
standalone, install it separately with `python -m pip install --pre --upgrade
"atflows==0.1.4b2"` and start it with `atflows`.

## Hermes preview

Install the packaged payload into the Hermes home and inspect its integrity:

```bash
atmem hermes install
atmem hermes status --json
```

Restart Hermes after installation. The payload is fail-closed and does not
read prompts, tool arguments, or model responses. AtFlows can observe Hermes
request/tool/error metadata through its local, loopback receiver; see the
AtFlows 0.1.4b2 release note for the copyable setup command.

## Migration and opt-in behaviour

No existing AtMem database migration is required. Existing Hermes settings are
left untouched. Installing the payload does not silently activate a memory
provider or create a scoped Hermes credential: activation still requires a
reviewed connection in the Hermes runtime. This is deliberate for the beta.

## Compatibility and limitations

- Python 3.10–3.13 and the existing AtMem encrypted-store contracts remain the
  supported baseline.
- The matching OpenClaw bridge is `2.3.8-beta.2` (`openclaw-memory-atmem@2.3.8-beta.2`)
  and is published as a prerelease npm package by the AtMem tag workflow.
- Hermes activation, provider selection, and end-to-end memory writes are not
  claimed by this beta until a scoped Hermes connection is configured and a
  real agent turn is verified.
- AtFlows telemetry is local-only by default; do not expose its receiver on an
  untrusted interface.

This is a prerelease. Report failures with the exact output of `atmem status`
and `atmem hermes status --json`.
