# AtMem 2.2.1 — complete Claude CLI flight evidence

AtMem 2.2.1 is a compatibility patch for OpenClaw execution paths that build a
prompt without firing `before_model_resolve`. In particular, live Claude CLI
turns could retrieve and inject governed memory correctly while their otherwise
complete Agent Black Box flights lacked `turn.input` evidence.

## Fixed

- The matched OpenClaw bridge now uses `before_prompt_build` as an idempotent
  fallback for authenticated turn-input observation and source staging.
- Standard execution paths that fire both hooks still record exactly one
  `turn.input` event and stage the user message once.
- Claude CLI-style paths that skip `before_model_resolve` now retain the prompt
  digest, automatic-capture source handoff, context decision, model boundaries,
  terminal event, and complete flight verdict without a host-side workaround.
- If two hooks expose different prompt bytes for one correlated turn, the first
  observation remains authoritative and the bridge emits a diagnostic warning.

## Security and compatibility

- AtMem continues to store prompt and response digests rather than raw content
  in Agent Black Box evidence.
- Memory authorization, candidate filtering, injection policy, signed delivery
  receipts, shadow mode, and canonical storage are unchanged.
- Pydantic AI and LangChain/LangGraph adapters begin their lifecycle at the
  framework run boundary and do not depend on this OpenClaw hook.
- AtBot remains pinned at `atmem-atbot==0.1.0a1`; this patch does not change its
  authority or storage boundary.

## Upgrade

```bash
python -m pip install --upgrade atmem==2.2.1
atmem openclaw upgrade
atmem control verify
```

The Python package pins and installs the matching
`openclaw-memory-atmem@2.2.1` bridge. Do not install the npm bridge separately.
Existing 2.1.x and 2.2.0 databases, record IDs, audit chains, memory mode, and
AtBot configuration are retained.

## Verification

The release gate covers Python 3.10 through 3.13, installed wheels, the 2.1.0
in-place upgrade drill, AtBot packaging, OpenClaw type checking and build, and
the complete OpenClaw hook harness. The bridge regression suite exercises both
dual-hook delivery and a Claude CLI-style prompt-build-only turn.
