## Windows publication blocker

Windows 11 build 26200, Python 3.12.6 x64, Git 2.46.2. Dependencies including
SQLCipher installed successfully. The final gate ran 351 tests: 152 passed,
22 skipped, 110 failed and 67 errors. The rich-source path explicitly raises
`NotImplementedError` because Windows has no qualified no-follow source reader.
The direct reproduction is
`tests/test_code_discovery.py::test_small_budget_and_max_ids_are_bounded` through
`atmem.knowledge.projections.read_authorized_file`. Do not remove this guard or
replace it with an ordinary path read to make the test pass. Other Windows
failures must be re-evaluated after a correctly tested reader exists; not every
failure has been independently attributed to that one cause.

The first Windows run also lacked Git on the SSH process PATH. The second run
explicitly supplied the already-installed Git location; the reader failure
remained. No global machine PATH or owner's agent settings were changed.

## Stable companion blocker

a stable-release prerequisite. Only Hermes metadata-label filtering currently
exists. Its S002–S005 implementation and canary/forwarding/upgrade gates must
finish before AtFlows 0.1.4 can publish. AtMem's new exact pin must not merge
before that version is genuinely installable from PyPI.

## Validation corrections retained

The initial full source run had six failures: release metadata changing while
the process was running, old guide/version inventory, unbracketed Spec 044 task
IDs, hard-coded local publishing paths and missing optional external-baseline
dependencies. Those were corrected; the complete final suite passed.
The first installed macOS harness also omitted two supporting test modules;
they were copied without copying the product package. Final installed imports
were checked against the selected environment's `site-packages`.

The first browser attempt lacked the matching Chromium runtime; the next found
the project's real selector omits a placeholder option. The driver now waits
for the specific project ID, not an assumed option count. The completed journey
uses only disposable test state and no owner data.
