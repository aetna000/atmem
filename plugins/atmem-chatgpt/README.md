# AtMem plugin — development package, not a public submission

Version 0.1.0 connects to the real optional `atmem.chatgpt` service. It contains
portable Agent Plugins 1.0 manifests, initial MCP configuration, skill and logo.
The loopback endpoint is for local MCP-client testing. ChatGPT web cannot reach
it without an authorized remote endpoint or supported secure tunnel. Neither a
valid ZIP nor local integration tests establish ChatGPT account permissions.

The built archive includes setup, uninstall, architecture, operations and review
guides in references/, generated from the repository's docs/chatgpt sources.
No endpoint, policy URL, recording, verified OpenAI developer or review approval
has been invented. A public package build refuses incomplete listing/deployment
metadata. Do not submit this development archive to the public directory.

The name in source identifies the repository author. The actual publisher must
be the user's verified individual identity selected in the submission portal.
