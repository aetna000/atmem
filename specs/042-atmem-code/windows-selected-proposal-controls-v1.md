# Selected-task public-proposal controls

For the four new source-qualified tasks, bind the existing private proposal
grader to the exact task/base, source/test roots, parser, image and runtime
projection. Use operator-authored configuration embedded in trusted bootstrap
code; no new model-input fields or caller-selected scope/path/provider are
introduced. Default single-task behavior remains restricted. Public workers
also bind the correct import layout and exact image-only artifact digests,
derived from the qualified unchanged snapshot. Reject changed/unknown extras.

Before model scoring, evaluate the unchanged public source and the upstream
reference as a public proposal, once each, in fresh constrained containers.
Create the reference public proposal by applying only differences between the
qualified original/reference snapshots to the verified public base. Do not
forward unchanged image-only runtime files as candidate source. Preserve all
actual streams in chunked protected evidence. Keep all failures, guards,
upstream scripts, expected counts and source-authority checks intact.

Require exact public Git blob/mode/membership checks, unchanged image-only
runtime bytes, no unused gold artifact written to the solver-proposal worker,
all expected parent target failures, full reference target resolution and full
regression passes without skips. Counts come from pinned upstream metadata,
not a favorable subset. These zero-model controls are not performance evidence.

The configured common public-test adapter retains its existing strict request
schema, bounded patch/selectors, source-only authorization and encrypted/full
evidence. Requests-1327's public test file is at `test_requests.py`, so only that
task may additionally select that exact root file; its default selector is that
file. Other tasks retain `tests/`. No arbitrary root-file selector is allowed.
Actual public-test execution/exposure remains a separate qualification gate.
