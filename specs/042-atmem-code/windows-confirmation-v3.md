### Terminal writer containment before source capture

The evaluator must not infer that all writers stopped merely because the CLI
parent exited. On the authorized WSL host, place each model supervisor in a
distinct root-owned cgroup-v2 case scope before irreversibly dropping to
uid/gid 1000. Descendants inherit that scope, including detached/background
processes; the unprivileged actor cannot change root-owned group membership.
After the supervisor terminates, terminate remaining scope members through the
kernel's `cgroup.kill` and verify `populated=0` before source capture. Do not
signal a reaped/reusable PID or an unrelated process group. Keep model, time,
tool, filesystem, network and compute budgets unchanged for both arms.

changes working directory, an attempted membership escape, and actual kernel
