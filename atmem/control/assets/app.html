Use Jev to improve candidate ordering

AtMem retrieves and authorizes memories first. Jev may reorder only those candidates; it cannot add, delete, or authorize memory.

Remote processing is opt-in. When enabled, eligible query and candidate text is sent to the configured Jev endpoint. The API key stays in the named environment variable and is never stored by AtMem.
